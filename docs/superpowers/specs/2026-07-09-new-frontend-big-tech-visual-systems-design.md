# OpenMontage 全新前端大厂视觉方案设计

日期：2026-07-09

## 目标

重新设计 OpenMontage 的全新商业化前端视觉，不基于当前项目已有工作台界面。输出两套完整产品视觉方案，用于比较后续落地方向。

本轮交付为效果图，不修改 React/Vite 前端代码。

## 风格方案

### A 套：2+3 融合

参考气质：Stripe/Linear 的商业可信感 + Canva/CapCut 的小白友好感。

定位：面向普通创作者、运营、小团队。视觉更明亮、更易懂、更适合充值转化。

视觉要点：

- 明亮浅色背景，清晰卡片和步骤。
- 青绿主色搭配蓝色、黄色、珊瑚色等少量友好辅助色。
- 文案直接告诉用户下一步怎么做。
- 充值、余额、套餐要显得可靠、透明。
- 创作流程要像模板工具一样简单。

### B 套：1+2 融合

参考气质：Apple/Runway 的高级 AI 影像创作感 + Stripe/Linear 的精致 SaaS 感。

定位：面向更高端的 AI 影像创作者、品牌团队、付费能力更强的用户。视觉更克制、更有电影感。

视觉要点：

- 深色或银灰背景，大留白和强层级。
- 影像预览、画面质感、项目资产要更突出。
- 颜色使用黑、银灰、冰蓝、极少量青色高光。
- 界面要高级，但不牺牲清晰的充值和项目管理。

## 输出清单

每套生成 14 张图，共 28 张：

1. `01-brand-entry`：产品入口页，解释这是 AI 短剧生成平台。
2. `02-login`：登录/注册页。
3. `03-creator-dashboard`：登录后的创作者首页。
4. `04-prompt-composer`：故事输入和生成配置。
5. `05-template-market`：模板/题材选择页。
6. `06-style-studio`：视频风格和视觉调性选择页。
7. `07-generation-progress`：生成进度页。
8. `08-storyboard-editor`：分镜编辑器。
9. `09-shot-regenerate`：单镜头重生/优化界面。
10. `10-asset-characters`：角色与素材库。
11. `11-final-preview`：成片预览、下载、分享。
12. `12-wallet-pricing`：充值套餐、余额、消耗预估。
13. `13-account-orders`：个人中心、订单、作品历史。
14. `14-optimization-board`：信息架构与优化方向说明板。

## 共同产品设定

- 用户登录后即可创作，不需要填写 API key、模型、网关、供应商。
- 前端暴露的是余额、点数、套餐、生成次数、作品历史。
- 核心流程：登录 -> 输入故事 -> 选模板/风格 -> 生成 -> 编辑分镜/素材 -> 预览下载 -> 充值续费。
- 全部界面使用中文，面向普通用户。

## 不做范围

- 不照抄任何大厂页面或品牌资产。
- 不使用真实 API key、网关 URL、模型名或供应商名。
- 不接入真实支付、登录、订单接口。
- 不修改当前应用代码。

## 成功标准

- A、B 两套视觉差异明显，分别体现亲民商业化和高级影像感。
- 每套都能独立说明完整产品闭环。
- 页面像可上线产品，而不是抽象概念图。
- 用户能从图中判断哪套更适合后续前端落地。
