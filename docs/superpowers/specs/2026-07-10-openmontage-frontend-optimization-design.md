# OpenMontage 工作台前端优化设计规格

日期：2026-07-10

## 1. 目标

在不扩张现有业务能力的前提下，把当前单页 OpenMontage 工作台优化为清晰、可刷新、可前进后退的多页面创作工作台。新界面采用已确认的方案 C，重点改善项目进入、AI 建立分镜、单分镜编辑、全局连续性设定、资源绑定和最终制作检查的效率。

本轮只优化工作台。登录、钱包、订阅、模板库和复杂应用设置不在本轮交付中。

## 3. 本轮范围

### 3.1 包含

- 浏览器本地项目列表、打开、创建、导入、导出和删除。
- 创建项目时输入标题、项目类型和总提示词。
- 由 AI 自动决定或推荐分镜数量，不增加用户手填分镜数量。
- 显示 AI 已规划的分镜数量，并使用后端返回的分镜提示词和结构化镜头数据。
- 独立分镜编辑页，每个分镜都提供 `AI 优化提示词`。
- 项目级全局设定页。
- 角色、场景、道具三类资源库及当前分镜绑定。
- 制作进度、工作流产物、一致性报告、成片预览和下载。
- 顶部保留 `充值` 入口，点击显示 `功能开发中`。
- 顶部保留紧凑的 `接口配置` 入口，使用抽屉承载现有 API Key、网关和模型字段。

### 3.2 不包含

- 登录、注册、账号中心。
- 钱包、余额、充值套餐、订阅或支付接口。
- 模板库、模板选择、风格市场。
- 团队协作、数据分析、作品市场。
- 复杂应用设置页。
- 新增后端生成能力或修改现有接口协议。
- 可拖拽剪辑、多轨音视频时间线、字幕轨或转场轨。

## 4. 信息架构与路由

使用真实浏览器路由，使返回、前进、刷新和深链访问行为可预测。

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 重定向 | 重定向到 `/projects` |
| `/projects` | 项目列表 | 浏览器本地项目管理 |
| `/projects/new` | 创建项目 | 输入标题、项目类型和总提示词 |
| `/projects/:projectId/storyboard` | 分镜编辑 | 工作台主页面 |
| `/projects/:projectId/settings` | 全局设定 | 项目级连续性设定 |
| `/projects/:projectId/resources` | 资源库 | 角色、场景、道具资源管理与绑定 |
| `/projects/:projectId/production` | 制作与成片 | 进度、产物、一致性与最终视频 |

不存在的钱包、充值、登录、设置或模板路由不得加入本轮路由表。

## 5. 共享工作台外壳

### 5.1 顶栏

- 左侧显示 OpenMontage 产品标识和当前项目标题。
- 项目内页面显示面包屑，支持回到项目列表。
- 右侧依次放置 `接口配置` 和 `充值`。
- `接口配置` 打开右侧抽屉，抽屉中复用当前网关地址、文本/图片/视频 Key 和模型字段。
- `充值` 不跳转页面；点击后显示非阻塞提示 `功能开发中`。
- 不显示余额、套餐价格或虚构账户头像。

### 5.2 项目导航

项目内页面使用稳定的左侧导航：

1. 分镜编辑
2. 全局设定
3. 资源库
4. 制作与成片

导航只表示页面切换，不使用标签页模拟路由。

### 5.3 全局反馈

- 页面级加载使用骨架或局部加载态，不清空已存在数据。
- 保存、导入、导出、生成和接口配置错误统一进入页面顶部错误提示。
- 短暂成功反馈和 `功能开发中` 使用 toast。
- 所有异步按钮在执行期间禁用并显示明确进行态。

## 6. 页面设计

### 6.1 项目列表

数据来自浏览器本地 `listProjectSummaries()`。

- 页面主操作为 `新建项目`。
- 项目以紧凑列表或网格呈现标题、更新时间、分镜数和成片状态。
- 每个项目支持打开、导出和删除。
- 删除前显示确认对话框，确认后调用现有本地删除能力。
- 顶部提供项目备份导入入口；导入成功后打开该项目的分镜页。
- 空状态只保留 `新建项目` 和 `导入项目`，不展示模板推荐。

### 6.2 创建项目

- 字段为项目标题、项目类型和总提示词。
- 项目类型继续使用 `single_video`、`mini_series`、`long_series` 三个现有值。
- 不提供模板选择、手动分镜数量或模型高级参数。
- 接口未配置完整时，主按钮禁用并提示用户打开 `接口配置`。
- 提交时调用现有 `createShortDramaProject()`，请求中不传 `shot_count`，由 AI 自动决定分镜数量。
- 创建完成后显示 `AI 已为你规划 N 个分镜`，其中 N 来自 `storyboard.shots.length`，随后进入该项目的分镜编辑页。
- 后端返回的每个 `Shot.prompt`、`shot_intent` 和 `shot_language` 直接成为初始分镜内容，不在前端伪造或二次填充。
- 创建失败时保留标题和总提示词，允许用户重试。

### 6.3 分镜编辑

桌面布局为左、中、右三部分：

- 左侧：可滚动分镜列表，显示序号、节拍、状态和缩略预览；点击切换当前分镜。
- 中间：当前分镜视频/占位预览、分镜核心信息，以及页面底部的只读分镜顺序条。
- 右侧：当前分镜检查器，编辑提示词、镜头意图、人物、地点、道具、资源绑定和镜头语言。

只读分镜顺序条按 `Shot.index` 排序，用于快速浏览和选择，不支持拖拽、裁剪或多轨编辑，不能在视觉上暗示完整非线性剪辑器。

每个分镜必须有 `AI 优化提示词` 操作：

1. 以当前编辑器中的提示词调用现有 `optimizePrompt()`。
2. 成功后把 `optimized_text`、`shot_intent`、`shot_language` 写入本地未保存草稿。
3. 优化成功不能自动调用 `saveShot()`，也不能自动调用 `regenerateShot()`。
4. 用户明确点击 `保存修改` 后才写入项目。
5. 用户明确点击 `重新生成` 后才生成视频；若仍有未保存草稿，先要求保存或使用禁用态提示。
6. 优化失败时保留优化前的全部编辑内容。
7. 每次优化成功后提供一次 `撤销优化`，恢复该次优化前的提示词、镜头意图和镜头语言。

切换分镜或离开页面时，如果存在未保存草稿，显示确认提示，避免静默丢失。

### 6.4 全局设定

这是项目级连续性设定，不是应用设置。保存使用现有 `saveContinuityPlan()`。

内容分为：

- 故事核心：`worldview`、`main_arc`。
- 视觉规则：`style_lock`、`visual_rules`、`taboos`。
- 角色与关系：`relationship_map`、`character_knowledge`、`character_status`、`relationship_changes`。
- 故事状态：`active_foreshadowing`、`resolved_foreshadowing`、`prop_state`、`current_locations`，并展示已有 `locations` 和 `props`。
- 分集规划：每集 `goal`、`conflict`、`twist`、`cliffhanger`、`inherited_state`、`locked` 和当前集。

单视频项目显示精简版：故事核心、视觉规则、角色关系、人物/道具/地点当前状态；隐藏分集规划、当前集和跨集继承字段。短剧和长剧显示全部内容。

页面必须明确提示：设定只影响后续提示词优化和生成，不回写或重生成已经完成的分镜。

### 6.5 资源库

资源类型严格使用现有 `AssetRecord.kind`：`character`、`scene`、`prop`。

- 顶部提供搜索、类型筛选和 `上传资源`。
- 主区域是可扫描的媒体网格，卡片显示资源名称、类型、参考图和关联分镜数。
- 选中资源后打开详情检查器，展示说明、提示词、参考图、媒体、关联分镜数，以及有数据时的一致性信息。
- `上传资源` 打开上传抽屉，字段复用现有 `ReferenceImageUploadRequest`。
- 详情检查器和上传抽屉互斥；打开一个必须关闭另一个。
- 当前分镜存在时，详情中提供 `绑定到当前分镜` 或 `从当前分镜移除`，通过现有 `saveShot()` 更新该分镜的 `asset_ids`。
- 关联分镜数优先根据当前 `storyboard.shots[].asset_ids` 计算，避免依赖可能滞后的展示字段。
- 不增加音频、字体、模板或素材市场分类。

### 6.6 制作与成片

- 使用现有事件订阅显示生成作业进度。
- 显示 `workflow_artifacts` 是否存在。
- 显示一致性得分和问题列表。
- 使用现有 `renderProject()` 生成成片。
- 有成片时显示视频预览、文件状态和下载按钮。
- 保留现有浏览器本地媒体缓存、项目导入导出和最终视频下载行为。
- 不添加发布、分享、团队审批或云端历史版本。

## 7. 状态与数据边界

### 7.1 共享项目状态

把当前 `App.tsx` 中与项目相关的状态和操作收敛到工作台状态层，页面通过明确接口读取和更新：

- 当前项目快照和加载状态。
- 当前选中分镜。
- API 网关和模型配置。
- 保存分镜、优化提示词、重新生成、保存全局设定、上传资源、渲染成片。
- 本地快照持久化、媒体 URL 解析和存储估算。
- 项目事件订阅和错误反馈。

路由中的 `projectId` 是打开项目的唯一来源。刷新项目页时使用 `loadProjectSnapshot(projectId)` 恢复浏览器本地快照；找不到时显示项目不存在，并提供回到项目列表的操作。

### 7.2 不改变的接口

- `createShortDramaProject`
- `createDraftProject`
- `saveShot`
- `optimizePrompt`
- `regenerateShot`
- `saveContinuityPlan`
- `uploadReferenceImage`
- `renderProject`
- 项目导入、导出和最终视频下载

前端重构不得要求新的后端字段。

### 7.3 提示词优化草稿

每个当前分镜的编辑草稿至少包含：

- `baseline`：最近一次已保存的可编辑字段。
- `draft`：当前表单值。
- `undoOptimization`：最近一次 AI 优化前的草稿，未发生优化时为 `null`。
- `dirty`：`draft` 与 `baseline` 是否不同。

保存成功后用服务端返回的 `Shot` 重置 `baseline` 和 `draft`；重新生成只接受已保存状态。

## 8. 视觉系统

- 明亮专业 SaaS 风格，中文界面。
- 页面背景使用白色和冷灰，正文使用深色中性色。
- 蓝色用于主操作，青绿色用于成功、已完成和一致性良好状态。
- 边框细而清晰，阴影克制，圆角不超过 `8px`。
- 页面布局以工具效率和信息扫描为主，不制作营销式首屏或装饰插画。
- 不使用紫色渐变、装饰光球、嵌套卡片或单一蓝紫色主题。
- 图标优先使用现有 Lucide；纯图标按钮必须有 tooltip 和无障碍名称。
- 固定格式区域使用稳定尺寸和响应式约束，异步状态不能导致布局跳动。

## 9. 响应式与无障碍

- `>= 1180px`：分镜页显示完整左/中/右三栏。
- `768px - 1179px`：左侧分镜列表和右侧检查器改为可打开面板，中间预览保持主区域。
- `< 768px`：项目导航可折叠，分镜列表、预览、检查器使用分段视图，所有表单单列显示。
- 键盘可以访问导航、资源筛选、分镜选择、抽屉和确认对话框。
- 抽屉和对话框打开后管理焦点，Esc 可关闭非阻塞面板。
- 状态颜色不能成为唯一信息来源，必须配合文本或图标。
- 所有按钮、输入框和媒体预览具有可识别的中文标签。

## 10. 验收标准

1. 项目列表能从浏览器本地加载、打开、导入、导出和删除项目。
2. 创建项目请求不包含 `shot_count`，完成后显示 AI 规划的实际分镜数。
3. 新项目返回的每个分镜都能看到后端自动填充的提示词。
4. 每个分镜都能 AI 优化提示词，优化结果是未保存草稿，并可撤销。
5. AI 优化不会自动保存或重新生成视频；保存与重新生成是两个明确步骤。
6. 全局设定按项目类型显示正确字段，保存使用现有连续性接口。
7. 资源库只包含角色、场景、道具，能搜索、筛选、上传、查看详情并绑定当前分镜。
8. 资源详情和上传抽屉不会同时出现。
9. 制作页保留事件进度、工作流产物、一致性、成片预览和下载。
10. 顶部 `充值` 点击只显示 `功能开发中`，不存在充值或钱包页面。
11. `接口配置` 位于紧凑抽屉中，仍能配置当前已有字段。
12. 刷新任一项目深链后能恢复相同项目和页面；不存在的项目有明确空状态。
13. 桌面、平板和手机布局中，文字、按钮和三栏内容不会重叠。
14. 前端单元测试、构建和关键浏览器流程验证通过。

## 11. 后续边界

后续切换到充值订阅模式时，再单独设计钱包/订阅页面，并把余额、充值记录、套餐和支付能力放入该模块。当前 `接口配置` 可以在账号化后迁入钱包或账户模块，但本轮不预埋虚构余额或支付数据结构。
