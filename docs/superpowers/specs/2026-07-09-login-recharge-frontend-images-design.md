# OpenMontage 登录充值版前端效果图设计

日期：2026-07-09

## 目标

把当前面向开发者的 OpenMontage 短剧工作台，重新包装成普通用户能直接上手的产品前端。用户不再输入 text/image/video API key，也不接触模型、网关、供应商配置；这些能力由后台统一管理。前端重点变成登录、充值、创作、分镜编辑、素材管理、渲染下载。

本轮交付是 6 张完整前端效果图，用作后续改版参考，不直接修改应用代码。

## 目标用户

目标用户是短剧创作者、运营人员、小团队老板和不懂技术的新手。他们需要的是“我写一个想法，系统帮我生成可用短剧视频”的清晰流程，而不是复杂参数面板。

## 信息架构

1. 登录/注册页：邮箱或手机号登录，突出安全可信和快速开始。
2. 充值/套餐页：展示余额、套餐、可生成次数和消耗说明。
3. 创作首页：输入故事想法，选择类型、时长、风格，然后生成分镜。
4. 分镜工作台：查看镜头、编辑当前镜头、重新生成单个镜头，默认隐藏高级参数。
5. 资源库/角色页：上传角色图、场景图、道具图，管理参考素材。
6. 最终渲染/下载页：查看视频生成状态、消耗、预览、下载和继续修改。

## 视觉方向

整体采用清爽 SaaS 加轻影视感：浅色背景、柔和青绿色主色、深墨色文字、少量温暖提示色。界面要安静、舒服、可长期使用，不做营销大首页，不使用大面积紫色渐变或过度装饰。

布局以小白清晰路径为核心：

- 顶部保留产品名、余额、充值入口、用户菜单。
- 左侧导航只放常用模块：创作、项目、资源库、充值、设置。
- 主区域优先显示下一步动作。
- 高级镜头语言、模型选择、供应商信息全部折叠或移到后台设置。

## 关键交互

- 用户登录后直接进入创作首页。
- 余额不足时，不弹复杂错误，显示充值引导和预计需要的点数。
- 分镜生成后，用户先看到镜头卡片和预览，再决定是否深入编辑。
- 单个镜头可以一键优化、一键重生、一键套用角色参考图。
- 最终视频页显示“正在排队、生成镜头、合成视频、完成”四步进度。

## 组件要求

- 按钮使用图标加短文字，常用动作要显眼。
- 卡片圆角不超过 8px，避免层层卡片嵌套。
- 表单文案使用普通人能懂的中文，例如“故事想法”“视频风格”“预计消耗”。
- 所有页面在 1440px 桌面尺寸下完整展示；后续实现时再适配移动端。

## 生成图片清单

1. `login-register`：登录/注册页，包含产品信任感和短剧生成预览。
2. `wallet-plans`：充值/套餐页，包含余额、套餐、生成次数和充值按钮。
3. `create-home`：创作首页，包含故事输入、类型、时长、风格和生成入口。
4. `storyboard-workbench`：分镜工作台，包含镜头列表、当前镜头编辑、角色/进度侧栏。
5. `asset-library`：资源库/角色页，包含上传、分类、素材卡片和角色锁定提示。
6. `render-download`：最终渲染/下载页，包含视频预览、进度、消耗、下载和继续编辑。

## 不做范围

- 不生成实际可点击代码。
- 不改当前 React/Vite 前端。
- 不接入真实登录、支付或计费接口。
- 不展示用户提供的真实 API key。

## 成功标准

- 6 张图能看出完整产品闭环：登录、充值、创作、编辑、资源、下载。
- 新手能在 5 秒内理解每个页面下一步该做什么。
- 视觉风格舒适、简洁、可信，适合后续直接落地到当前 OpenMontage 前端。
- 效果图不暴露底层模型、网关、API key 等开发者概念。
