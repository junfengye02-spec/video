# mise studio「轻盈 Mac 创作工具」视觉与动效执行计划

日期：2026-07-19  
状态：待确认后执行  
适用范围：生产前端 `web/src`  
配套架构计划：`docs/2026-07-19-youmind-mac-frontend-rearchitecture-plan.md`

## 1. 设计方向

将 mise studio 改造成一套轻盈、安静、具有创作氛围的 Mac 风格视频工作台。

它不是满屏毛玻璃，也不是传统 SaaS 后台。核心特征是：

- 暖灰画布。
- 半透明顶栏。
- 三级表面层次。
- 极细边线。
- 柔和的组合阴影。
- 媒体优先的内容表达。
- 清晰而克制的字号梯度。
- 连续、快速、能够解释状态变化的动效。

视觉可以借鉴 YouMind 的舒适感和秩序感，但不复制其品牌资产、文案和专有图形。

## 2. 核心原则

### 2.1 安静，不寡淡

- 大面积区域使用暖灰和近白色，不使用刺眼纯白铺满整个屏幕。
- 黑色只用于核心文字和主操作，不做大面积深色背景。
- 品牌绿只用于焦点、成功状态和少量强调。
- 通过媒体、排版和空间建立层级，而不是不断增加卡片边框。

### 2.2 有层次，不堆玻璃

只允许三级表面：

1. 画布：应用背景和中央工作区底色。
2. 内容表面：文档、卡片、列表和编辑区。
3. 浮动表面：菜单、抽屉、Dialog、Popover 和临时命令栏。

毛玻璃只用于顶栏、浮动工具条和少量覆盖层。普通文档、表单和列表保持清晰实体表面。

### 2.3 动效解释变化

- 按钮动效解释“可以点击、正在点击、已经完成”。
- 页面动效解释“内容从哪里来、当前焦点在哪里”。
- 列表动效解释“项目或镜头发生了新增、删除、重排”。
- 抽屉动效解释“当前仍在同一上下文，只是打开了更多信息”。

禁止为装饰而动画文字、视频像素和长文档。

## 3. 设计 Token

以下为第一轮候选值，实施时需要通过真实页面截图和对比度检查微调。

### 3.1 颜色

```css
:root {
  --canvas: #f3f3f1;
  --canvas-deep: #ececea;
  --surface: #fbfbfa;
  --surface-raised: #ffffff;
  --surface-floating: rgb(255 255 255 / 88%);

  --ink: #1d1d1f;
  --ink-secondary: #515154;
  --ink-muted: #77777b;
  --ink-faint: #a1a1a6;

  --line: rgb(29 29 31 / 8%);
  --line-strong: rgb(29 29 31 / 13%);
  --selection: rgb(29 29 31 / 6%);

  --accent: #2f7654;
  --accent-soft: #eaf4ee;
  --warning: #94651c;
  --danger: #b42318;
}
```

要求：

- 业务组件不得自行定义新的品牌色。
- 媒体内容可以有丰富颜色，界面 chrome 保持中性。
- 禁止蓝紫渐变成为主视觉。

### 3.2 字体与字号

字体栈：

```css
font-family:
  -apple-system,
  BlinkMacSystemFont,
  "SF Pro Text",
  "SF Pro Display",
  "PingFang SC",
  "Microsoft YaHei",
  "Segoe UI",
  sans-serif;
```

字号梯度：

| 用途 | 字号 / 行高 | 建议字重 |
| --- | --- | ---: |
| 首页主标题 | 36–42 / 1.12 | 650–700 |
| 页面标题 | 26–30 / 1.2 | 650–700 |
| 区块标题 | 18–20 / 1.35 | 620–680 |
| 卡片标题 | 14–16 / 1.4 | 600–650 |
| 正文 | 14–15 / 1.6 | 400–500 |
| 辅助文字 | 13 / 1.5 | 450–550 |
| Caption | 12 / 1.45 | 500–600 |

要求：

- 正文不得普遍降到 12px。
- 10–11px 仅用于时间码、序号和非关键元数据。
- 中文标题不使用过重的 800–900 字重。

### 3.3 圆角

| 元素 | 圆角 |
| --- | ---: |
| 输入框、普通按钮 | 8–10px |
| 项目卡、镜头卡、文档面板 | 12–14px |
| Composer、Drawer、Dialog | 16–18px |
| Chip、状态标签 | pill |

圆角用于区分表面类型，不允许所有元素统一大圆角。

### 3.4 边线与阴影

普通内容表面：

```css
border: 1px solid var(--line);
box-shadow:
  0 1px 1px rgb(0 0 0 / 3%),
  0 8px 24px rgb(0 0 0 / 4%);
```

浮动表面：

```css
border: 1px solid rgb(255 255 255 / 55%);
box-shadow:
  0 1px 2px rgb(0 0 0 / 7%),
  0 14px 38px rgb(0 0 0 / 10%),
  inset 0 1px 0 rgb(255 255 255 / 70%);
```

禁止使用单层浓黑大阴影。

## 4. 全局壳层

### 4.1 顶栏

- 高度建议 54–58px。
- 背景使用近白半透明色，`backdrop-filter: blur(18px) saturate(140%)`。
- 使用 1px 底部边线，不使用明显投影。
- 左侧显示品牌和项目上下文。
- 中间显示阶段导航。
- 右侧仅保留余额、账户和高频操作。
- 图标按钮默认透明，hover 时出现浅色圆角底。

### 4.2 页面画布

- 全局背景使用暖灰画布。
- 普通页面内容宽度保持稳定，不在大屏无限拉宽。
- 创作工作台可以占满可用高度，但中央媒体舞台必须获得最大空间。
- 页面之间保持一致的顶部、左右安全间距。

### 4.3 页面切换

- 顶栏不重绘、不闪烁。
- 主内容使用 200–240ms 的淡入和 4–6px 轻位移。
- 仅切换内容区域，不让整个浏览器画面飞入飞出。
- 返回上一阶段时保持合理滚动位置和选中状态。

## 5. 创作首页

### 5.1 目标

首页首先是创作入口，其次才是项目管理页。

### 5.2 布局

- 页面顶部保留简短主标题和说明。
- 大 Composer 是第一视觉焦点。
- 模式、画幅和项目类型放在 Composer 底部工具栏。
- 低频配置折叠进 Popover，不把所有 select 永久铺开。
- 最近项目使用媒体卡片，而不是后台式横向数据行。

### 5.3 项目封面

封面获取顺序：

1. 已有成片的 poster 或视频首帧。
2. 第一个已生成镜头的预览图。
3. 第一个可用资源图。
4. 最后才使用中性占位图。

卡片信息：

- 封面。
- 项目标题。
- 当前阶段或成片状态。
- 镜头数和最近更新时间。
- hover 后出现“继续创作”和更多菜单。

### 5.4 动效

- 项目卡 hover：160ms，上移 2px，阴影轻微增加。
- 封面 hover：180ms，最多放大到 1.015。
- 更多菜单：200ms 淡入并缩放 0.98 → 1。
- 模式切换：选中背景连续滑动，不直接闪切。
- 创建中：按钮宽度不变化，图标转为 spinner，文案淡换。
- 创建成功：按钮短暂成功反馈后再进入项目。

## 6. 灵感对话页

### 6.1 目标

保持双栏结构，但左侧像轻量对话，右侧像真正的创作文档。

### 6.2 左侧对话区

- AI 消息不使用厚重聊天气泡，采用头像、名称和正文流。
- 用户消息使用轻灰或浅绿胶囊，与 AI 消息区分。
- 建议选项使用轻量 Chip，不做粗边框按钮墙。
- Composer 固定在底部，但与内容之间保留空气感。
- 消息列表负责滚动，整页顶栏和右侧文档保持稳定。

### 6.3 右侧创意文档

- 使用温暖近白纸张表面。
- 文档宽度控制在适合阅读的范围，不无限横向铺开。
- 使用轻边线、柔阴影和较大的内部留白。
- 标题、摘要、关键事实和故事方向形成清楚的编辑层级。
- 确认命令栏位于文档底部或底部 sticky 区域。

### 6.4 动效

- 新消息进入：180ms 淡入 + 6px 上移。
- 用户发送：立即插入本地消息，不等待服务端后才出现。
- AI 思考态：使用三个低调呼吸点或文字状态，不使用大面积骨架闪烁。
- 简报字段更新：160–200ms 交叉淡化，只更新字段，不重放整张文档动画。
- 确认按钮成功后，文档轻微高亮并进入下一阶段。

## 7. 分镜工作区

### 7.1 目标

把中央媒体舞台变成绝对主角，左右栏只是辅助工具。

### 7.2 布局

桌面布局：

```text
镜头列表  |           中央媒体舞台           |  镜头检查器
240–280px |              flex                | 320–360px
```

- 左栏展示缩略图、镜头名、时长和状态。
- 中央展示当前媒体、播放控制和底部胶片条。
- 右栏展示叙事、镜头语言、资源绑定和生成操作。
- 栏与栏之间使用极细分隔线，不使用三张厚重卡片。
- 小屏幕下左右栏转换为 Drawer 或可折叠面板。

### 7.3 选中镜头

- 使用浅色浮层、细描边和轻微内高光。
- 不使用高饱和整块背景。
- 状态图标和文字同时表达完成、生成中和失败。
- 镜头列表滚动时保持当前选中项可见。

### 7.4 中央媒体舞台

- 媒体区域使用深中性色承托图片和视频。
- 图片或视频保持稳定 aspect ratio，切换时不改变舞台尺寸。
- 无媒体时显示克制的创作状态，不使用巨大空白表单。
- 播放控制贴近媒体底部，默认降低存在感。

### 7.5 动效

- 镜头切换：180–220ms 交叉淡化。
- 选中浮层：160ms 连续移动或淡换。
- 胶片条自动滚动：240–300ms，避免突然跳位。
- 右侧检查器 Tab：180ms 淡入，不左右长距离滑动。
- 保存成功：状态文字和图标轻微回弹一次，不弹 Toast 轰炸用户。
- 重新生成：按钮进入 loading，媒体舞台保留旧内容并显示生成覆盖层。

## 8. 按钮和通用反馈

### 8.1 主按钮

- 近黑背景、白色文字。
- hover：背景略亮、阴影轻微增加。
- active：缩放至 0.985 或下移 1px。
- loading：保持原尺寸。
- success：spinner 切为勾选，120–180ms 轻回弹。
- disabled：降低对比度但仍保持文字可读。

### 8.2 次按钮与图标按钮

- 默认透明或浅表面。
- hover 时显示浅色背景和明确 Tooltip。
- 危险操作只有在菜单或确认界面中使用红色。

### 8.3 菜单、Popover 和抽屉

- Menu/Popover：180–220ms，淡入 + 0.98 缩放。
- Drawer：260–320ms，短距离位移并同时淡入遮罩。
- Dialog：240–280ms，遮罩先出现，面板轻微放大。
- 关闭后焦点返回触发按钮。
- 动画中重复点击不能创建多个浮层。

### 8.4 列表更新

- 新增项目、镜头或资源时保留其他元素位置连续。
- 删除前先执行确认；确认后元素高度平滑收起。
- 筛选和搜索只动画结果容器，不逐个延迟播放大量卡片。

## 9. Motion Token

```css
:root {
  --motion-instant: 100ms;
  --motion-fast: 160ms;
  --motion-ui: 200ms;
  --motion-panel: 280ms;
  --motion-slow: 320ms;

  --ease-standard: cubic-bezier(.2, .8, .2, 1);
  --ease-out: cubic-bezier(.16, 1, .3, 1);
  --ease-in: cubic-bezier(.4, 0, 1, 1);
}
```

实现规则：

- hover、focus、press 优先使用 CSS。
- 菜单、抽屉、Dialog 和布局重排使用统一 motion primitive。
- 禁止页面组件自行复制 easing 和 duration。
- 禁止 `transition: all`。

### 9.1 Reduced motion

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    scroll-behavior: auto !important;
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

Reduced motion 下：

- 保留状态变化和焦点反馈。
- 取消位移、缩放、弹簧和自动平滑滚动。
- 不隐藏 loading、成功或错误状态。

## 10. 代码落地约束

视觉改造不得继续扩大当前全局样式和巨型页面组件。

- 新页面样式使用 CSS Modules 或 feature 根作用域。
- 不再向 `web/src/styles/pages.css` 添加整页规则。
- 响应式规则与组件放在一起，不再继续堆进单一 `responsive.css`。
- 通用 Button、Menu、Drawer、Dialog、Tabs 只实现一次。
- 项目、镜头、资源等业务组件放入对应 feature。
- 页面只负责布局组合，不直接处理底层媒体缓存和请求竞态。
- 单个表现组件超过约 300 行时触发拆分评审。
- 单个 CSS Module 超过约 300 行时触发拆分评审。

## 13. 验收标准

### 13.1 视觉

- 页面具备明确的画布、内容表面和浮动表面三级层次。
- 顶栏具有轻微透光感，但正文区域没有滥用玻璃。
- 正文和辅助文字在常用桌面尺寸下清楚可读。
- 项目首页首先看到媒体和创作入口，而不是后台表格。
- 灵感文档具有纸张感和稳定阅读宽度。
- 分镜中央媒体明显强于左右工具栏。

### 13.2 交互

- 所有可点击控件具备 hover、active、focus 和 disabled。
- loading 状态不引起按钮和布局跳动。
- 菜单、抽屉和 Dialog 动画连续且焦点正确。
- 镜头、项目和资源切换没有突然闪白或尺寸跳变。
- 快速重复点击不会产生重复请求或多个浮层。

### 13.3 性能与可访问性

- 常用动画只使用 opacity 和 transform，避免高频 layout thrashing。
- 典型桌面设备上动画目标为稳定 60fps。
- `prefers-reduced-motion` 下完整可用。
- 键盘可以操作主要导航、菜单、Dialog、Composer 和镜头选择。
- 390px、1024px、1440px、1600px 无页面级横向溢出。

### 13.4 工程质量

- 不新增整页全局 CSS。
- 不复制 Button、Menu、Drawer 和 Dialog 实现。
- 页面组件不承载媒体缓存、请求竞态和持久化逻辑。
- 前端测试与 production build 通过。
